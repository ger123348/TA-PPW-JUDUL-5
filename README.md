# TA-PPW-JUDUL-5

Gerhana Malik Ibrahim (2315061032)

Web yang saya buat merupakan web berbasis HTML, CSS, dan JavaScript yang digunakan untuk melakukan perhitungan aritmatika dasar seperti tambah, kurang, kali, dan bagi. Kalkulator ini memiliki tampilan modern bertema hitam–oranye dan dilengkapi fitur lengkap seperti tombol angka, operator, tanda desimal, clear (C), clear entry (CE), serta tombol equals (=). Selain perhitungan umum, aplikasi ini juga mendukung memory functions (MC, MR, M+, M−), menampilkan riwayat 5 perhitungan terakhir, serta menyediakan dukungan input melalui keyboard. Seluruh fitur dirancang responsif sehingga nyaman digunakan pada perangkat mobile maupun desktop.
